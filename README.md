# Student Grade Management System — Functions Version

## About the Project

A beginner-friendly student management system built with Python functions in a Jupyter Notebook. The project helps manage student records, grades, averages, and academic performance.

## Features

* Add student records
* Display student information
* Search for a student
* Calculate student averages
* Determine academic status
* Display class statistics
* Validate user inputs

## Technologies Used

* Python 3
* Jupyter Notebook
* Functions
* Lists and Dictionaries
* Conditional Statements
* Loops
* Input Validation

## Grading System

* Excellent: 85 and above
* Very Good: 75 to less than 85
* Good: 60 to less than 75
* Passed: 50 to less than 60
* Failed: Below 50

## How to Run

1. Install Python 3 and Jupyter Notebook.
2. Clone or download this repository.
3. Open the project notebook (`.ipynb`) in Jupyter Notebook or VS Code.
4. Run the notebook cells in order.
